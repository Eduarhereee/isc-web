# Cambio de imagen — Presentación ISC (19 nov 2026)

La sección que inicia **“Cada instalación tiene un reto”** utiliza ahora una única imagen de stock de personas en una planta industrial, en lugar del collage de trabajos propios.

**Fuente:** TECNIC Bioprocess Solutions, “Two technicians discuss factory equipment”, Unsplash.
https://unsplash.com/photos/two-technicians-discuss-factory-equipment-5p8SUWuCZ2U

**Licencia:** Unsplash License, apta para uso comercial. https://unsplash.com/license

**Imagen remota:** https://images.unsplash.com/photo-1748348209623-906c42dd1f7b?auto=format&fit=crop&w=2000&q=86

Se usa una URL remota: el navegador necesita conexión a Internet para mostrar la foto de stock. Si no carga, el sitio muestra automáticamente una fotografía de ISC ya incluida (assets/proyectos/cv-p20-02.webp). La leyenda la identifica como imagen ilustrativa, no como personal de ISC.

Se modificaron únicamente `index.html` y `assets/site.css`, además de agregar la recuperación de imagen remota en `assets/site.js`. El resto del sitio se conserva.

Para publicarlo en GitHub Pages: descomprime el ZIP, copia el **contenido** directamente en la raíz del repositorio y haz commit + push.

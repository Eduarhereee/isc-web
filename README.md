# Ingeniería y Servicios Camarillo (ISC)

Repositorio destinado al sitio web corporativo de ISC, preparado para publicarse en GitHub Pages.

## Publicación inicial

La versión completa del sitio está en el archivo `ISC_Proyecto_Completo_Clientes_Hero_Redisenado_2026-11-19.zip` entregado en el chat. Copiar **el contenido extraído** a la raíz del repositorio y hacer commit en `main`; `index.html` y `.nojekyll` deben quedar en la raíz.

Posteriormente configurar Settings → Pages → Deploy from a branch → main → /(root).

Nota: hasta completar la carga, el sitio no está publicado.
